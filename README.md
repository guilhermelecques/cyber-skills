DedSec Learning Lab

Um repositório de aprendizagem prática focado em Linux, redes, Python, Git e fundamentos de cibersegurança.

Sobre

Este repositório documenta a minha jornada de aprendizagem em cibersegurança e desenvolvimento de software através de exercícios práticos, notas técnicas, experiências e projetos.

Tópicos de Aprendizagem
Linux: ferramentas de linha de comando, permissões de ficheiros e fundamentos de sistemas.
Redes: endereçamento IP, DNS, TCP/UDP e análise de tráfego de rede.
Python: fundamentos de programação, manipulação de ficheiros, expressões regulares e APIs.
Git e GitHub: controlo de versões e fluxos de trabalho de desenvolvimento colaborativo.
Fundamentos de Segurança: autenticação, autorização, hashing, encriptação e práticas de desenvolvimento seguro.
Projetos
1. Analisador de Logs (Log Analyzer)

Uma ferramenta desenvolvida em Python que analisa ficheiros de registo fictícios, contabiliza erros, filtra eventos e gera relatórios.

2. Notas sobre Tráfego de Rede (Network Traffic Notes)

Experiências documentadas de análise de tráfego de rede gerado num ambiente controlado.

3. API de Eventos de Segurança (Security Events API)

Uma pequena API que permite receber, consultar e filtrar eventos de segurança fictícios.

Objetivos
Desenvolver competências técnicas através da prática.
Melhorar as capacidades de resolução de problemas e depuração de código.
Documentar aquilo que aprendo e os recursos que utilizo.
Criar projetos que demonstrem a minha evolução e os conhecimentos adquiridos.
Aviso

Todas as experiências de segurança são realizadas em ambientes controlados e autorizados, utilizando dados fictícios ou gerados por mim.

Estado do Projeto

Este repositório está em constante desenvolvimento e irá evoluir à medida que aprendo novos conceitos e desenvolvo novos projetos.
